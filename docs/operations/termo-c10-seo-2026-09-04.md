# C10 — Fortalecimento do SEO e das páginas de entrada

## Resultado técnico

Implementação e publicação concluídas em 4 de setembro de 2026.

Foram criadas três páginas com intenção de busca clara:

- `/leis-da-termodinamica.html`;
- `/exercicios-de-termodinamica.html`;
- `/simuladores-de-termodinamica.html`.

Cada página possui título e descrição próprios, H1 único, canonical, dados
estruturados, conteúdo introdutório e ligações para home, mapa, app e recursos
relacionados. A home passou a apontar para essas rotas e os quatro sitemaps de
compatibilidade foram atualizados.

Também foi adicionado redirecionamento permanente de `/home.html/home.html`
para `/home.html`, eliminando a duplicação indicada na análise de partida.

## Validação

- `npm run test:seo`: 5/5 testes aprovados;
- `npm run check`: aprovado;
- `npm run test:analytics`: 7/7 testes aprovados;
- `npm run test:ratings`: 6/6 testes aprovados;
- `npm run test:gamification`: 8/8 testes aprovados;
- três páginas responderam HTTP 200 no servidor local;
- inspeção visual e semântica da página de leis aprovada.

## Publicação

A Vercel CLI não estava autenticada, mas o push do commit `e535340` para a
branch principal acionou a implantação automática. A validação em produção
confirmou HTTP 200 nas três páginas, presença no sitemap e HTTP 308 de
`/home.html/home.html` para `/home.html`.

## Acompanhamento

Depois da publicação, comparar no Search Console cliques, impressões, CTR e
posição média em 30, 60 e 90 dias. Solicitar indexação somente das três páginas
novas e da home alterada.
