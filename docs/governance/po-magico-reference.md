## Uso no TERMO

O TERMO adota a classificação
`INTERACTIVE_BOOK + EDUCATIONAL_MATERIAL + APP` e aplica o sistema de Changes,
os gates e a política adaptativa de modelos do arquivo indicado acima.

Esta referência aponta para uma fonte externa preservada. Atualizações futuras
do Pó Mágico exigem uma Change própria que registre o novo arquivo e a nova
revisão; a referência não deve avançar silenciosamente para `latest`.

## Limites

- A disponibilidade de um modelo precisa ser confirmada no ambiente de execução.
- Uma rota recomendada não prova qual modelo executou uma tarefa.
- Tokens, latência, custo, reasoning e fallback só podem ser registrados quando
  houver telemetria ou metadados verificáveis.
- Regras do Pó Mágico não autorizam commit, push, deploy ou mutações remotas no
  TERMO sem autorização específica.
