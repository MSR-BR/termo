# Objetivo — Change 035

Produzir um inventário verificável das superfícies públicas do TERMO e definir
uma sequência de migração que permita tornar o repositório principal privado
sem interromper a landing, o app, o GitHub Pages, o SEO ou os deploys no Vercel.

## Classificação

`INTERACTIVE_BOOK + EDUCATIONAL_MATERIAL + APP`

## Resultado observável

- cada arquivo de `docs/` está classificado como público ou interno;
- a exposição atual pelo GitHub Pages e pelo Vercel está documentada;
- o índice técnico dos exercícios IA está classificado como administrativo;
- os riscos de uma eventual privatização estão explícitos;
- a decisão humana de manter o repositório público está registrada;
- a melhoria de segurança independente da privatização está separada do
  programa suspenso.

## Limites

- Fora do escopo: criar repositório, alterar GitHub Pages, mudar a visibilidade
  do TERMO, modificar o Vercel, proteger rotas, trocar canonical, fazer commit,
  push ou deploy.
- Nenhuma funcionalidade, página ou conteúdo científico é alterado.
- A privatização foi suspensa e não pode ser retomada sem uma nova decisão
  humana explícita.
- Uma futura T36 poderá tratar da exposição de arquivos internos no Vercel e do
  índice administrativo sem alterar a visibilidade do GitHub.
