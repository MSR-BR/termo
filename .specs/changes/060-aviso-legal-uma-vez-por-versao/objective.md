# Objetivo

Impedir que o aviso de acesso opcional interrompa cada nova janela do TERMO para uma conta já conectada, preservando o acesso manual às preferências legais.

## Classificação do projeto

`INTERACTIVE_BOOK + EDUCATIONAL_MATERIAL + APP`

## Limites

- Não alterar consentimento salvo, autenticação, banco de dados nem autorização.
- A lembrança local indica apenas que o aviso foi exibido; não representa aceite.
